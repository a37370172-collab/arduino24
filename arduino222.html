아두이노 신호등 프로젝트

2026년 10월 23일 수업 정리 · 배선 정보와 Arduino 코드 명령어

1. 프로젝트 동작 요약

처음에는 초록 LED가 켜집니다. 버튼을 누르면 초록불이 꺼지고, 노란불이 3초, 빨간불이 10초 켜진 뒤 초록불로 돌아옵니다.

초록불 시작 → 노란불 3초 → 빨간불 10초 → 초록불 복귀

사용 핀: 초록 LED D11 · 노란 LED D10 · 빨간 LED D9 · 버튼 D8

2. 준비물

  • Arduino Uno (또는 호환 보드)와 USB 케이블
  • 브레드보드와 점퍼선
  • 초록·노란·빨간 LED 각 1개
  • LED용 저항 3개 (각 220Ω~330Ω 권장)
  • 푸시 버튼 1개

3. 배선 연결표

부품연결 방법설명
초록 LEDD11 → 저항(220Ω~330Ω) → LED 긴 다리(+)
LED 짧은 다리(-) → GND		시작할 때 켜짐
노란 LEDD10 → 저항(220Ω~330Ω) → LED 긴 다리(+)
LED 짧은 다리(-) → GND		버튼 입력 후 3초 켜짐
빨간 LEDD9 → 저항(220Ω~330Ω) → LED 긴 다리(+)
LED 짧은 다리(-) → GND		노란불 다음 10초 켜짐
푸시 버튼한쪽 다리 → D8
반대쪽 다리 → GND		INPUT_PULLUP 사용
공통 접지Arduino GND → 브레드보드 GND 레일LED 음극과 버튼 GND가 공통으로 연결됨
주의: LED마다 저항을 하나씩 연결하세요. 버튼은 INPUT_PULLUP 설정이므로 D8과 GND 사이에 연결하며, 누르지 않았을 때는 HIGH, 눌렀을 때는 LOW로 읽힙니다.

4. 전체 Arduino 코드

int G = 11;
int Y = 10;
int R = 9;
int button = 8;

void setup() {
  pinMode(G, OUTPUT);
  pinMode(Y, OUTPUT);
  pinMode(R, OUTPUT);
  pinMode(button, INPUT_PULLUP);

  // 처음에는 초록색
  digitalWrite(G, HIGH);
  digitalWrite(Y, LOW);
  digitalWrite(R, LOW);
}

void loop() {
  if (digitalRead(button) == LOW) {
    delay(50);

    if (digitalRead(button) == LOW) {
      // 초록색 끄기
      digitalWrite(G, LOW);

      // 노란색 3초
      digitalWrite(Y, HIGH);
      delay(3000);
      digitalWrite(Y, LOW);

      // 빨간색 10초
      digitalWrite(R, HIGH);
      delay(10000);
      digitalWrite(R, LOW);

      // 초록색 다시 켜기
      digitalWrite(G, HIGH);

      // 버튼에서 손을 뗄 때까지 대기
      while (digitalRead(button) == LOW) {
        delay(10);
      }
    }
  }
}

5. 주요 명령어 정리

명령어뜻이 코드에서의 용도
int정수형 변수를 선언핀 번호를 G, Y, R, button에 저장
pinMode(pin, OUTPUT)핀을 출력으로 설정LED를 제어
pinMode(pin, INPUT_PULLUP)내부 풀업 저항을 사용해 입력으로 설정버튼 상태를 읽음
digitalWrite(pin, HIGH)디지털 출력 HIGHLED 켜기
digitalWrite(pin, LOW)디지털 출력 LOWLED 끄기
digitalRead(pin)디지털 핀 상태 읽기버튼이 눌렸는지 확인
if (...)조건이 참일 때 코드 실행버튼이 눌렸을 때 신호등 순서 실행
delay(3000)3000밀리초, 즉 3초 대기노란불 유지
delay(10000)10000밀리초, 즉 10초 대기빨간불 유지
while (...)조건이 참인 동안 반복버튼에서 손을 뗄 때까지 대기
setup()전원이 켜지거나 리셋될 때 한 번 실행핀 설정 및 초기 초록불 점등
loop()계속 반복 실행버튼 입력을 계속 확인

6. 작동 시간과 버튼 동작

  • 50ms 대기: 버튼 접점의 짧은 흔들림(바운스)을 줄이기 위한 간단한 디바운싱입니다.
  • 노란불 3초: delay(3000)
  • 빨간불 10초: delay(10000)
  • 버튼을 놓을 때까지 대기: 누르고 있는 버튼 때문에 신호등이 연속 실행되는 것을 방지합니다.
현재 코드는 delay()로 기다리는 동안 다른 버튼 입력을 처리하지 않습니다. 버튼을 누른 뒤 한 사이클이 끝나면 초록불로 돌아오며, 다시 버튼을 눌러 다음 사이클을 시작할 수 있습니다.

7. 업로드 및 점검 순서

  1. USB 케이블로 Arduino를 컴퓨터에 연결합니다.
  2. Arduino IDE에서 보드 종류와 포트를 선택합니다.
  3. 위 코드를 새 스케치에 붙여 넣고 확인(컴파일)합니다.
  4. 업로드한 뒤 처음에 초록 LED가 켜지는지 확인합니다.
  5. 버튼을 눌러 노란불 3초, 빨간불 10초 후 초록불로 돌아오는지 확인합니다.
전원을 연결하기 전에 LED 방향, 저항, GND 공통 연결을 확인하세요. LED가 켜지지 않으면 극성, 핀 번호, 브레드보드 연결 위치를 다시 점검합니다.
